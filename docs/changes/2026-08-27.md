# 0831

- UI: the six Piko entries are unified with native 4:3 and 16/20/24px responsive spacing; 960×720, 24fps hover videos and first-frame covers are wired in, using a single video layer and non-geometric color feedback to eliminate cropping and jitter.
- UI: the history assets dialog is rebuilt with a fixed five columns; image hover uses a 50% overlay and 10px blur, and prompts are fixed to two lines with a persistent expand entry.
- UI: canvas snapping is computed by same-edge, centerline, and adjacent-edge, using 8px snapping and 12px release hysteresis; it supports absolute group coordinates, end-frame locking, and a 1px light dashed line, enabled by default.
- UI: dragging nodes and multi-selections enters focus mode, temporarily hiding the toolbar, action panel, menus, hints, and connection controls; node, draft, and snapping feedback are kept and restored on release.
- UI: the Piko game entry in the bottom bar is replaced by a 30px-high transparent flat pixel-character wordmark, with default opacity raised to 90% and moved up 1px for optical alignment; the capsule hover background and separate text are removed, leaving only light brightness feedback and full button semantics.
- UI: the canvas shortcut bar's "History" is renamed "History assets", so the entry name matches its asset-browsing purpose.
- UI: the asset library clearly splits management and selection modes; in management state cards become detail entries, and batch capability is narrowed to "Batch delete" of locally uploaded assets only, while mainline assets can still be viewed in batch state.
